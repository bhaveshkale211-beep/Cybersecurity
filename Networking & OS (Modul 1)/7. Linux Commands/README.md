# Topic 7 — Linux Practical CMD Interface

This topic is all terminal, all the time — building actual command-line fluency in Kali rather than just knowing the theory. Starting with the basics everyone needs before anything more advanced makes sense.

## Tools I used

- Kali Linux terminal

## Assignments

| # | Assignment | What it covers |
|---|---|---|
