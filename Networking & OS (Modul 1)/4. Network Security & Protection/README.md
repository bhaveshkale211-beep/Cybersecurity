# Topic 4 — Network Security & Protection

## 📖 Overview

This topic moves from "how networks work" into "how networks are protected" — practically comparing the security tools and techniques used to control, encrypt, and secure network traffic at different layers.

## 🛠️ Tools Used

- Windows Proxy configuration
- Command Prompt (`ipconfig`, `netstat`)
- Proton VPN
