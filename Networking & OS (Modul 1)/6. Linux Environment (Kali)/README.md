# Topic 6 — Linux & Kali Linux

Getting comfortable with Linux, using Kali as the base — starting with setting it up properly in a VM, then actually spending time in it to see how it's laid out and how the filesystem is organized.

## Tools I used

- VMware Workstation
- Kali Linux

## Assignments

| # | Assignment | What it covers |

| 01 | [Kali Linux Installation Using VMware](./Assignment-01-Kali-Linux-Installation-VMware/) | Setting up Kali in a VM — allocating RAM/CPU/disk, installing it, and checking it actually worked with a few terminal commands |

| 02 | [Exploring the Kali Linux Environment](./Assignment-02-Exploring-Kali-Linux-Environment/) | Getting around the Xfce desktop, Application Menu, System Settings, and running some terminal commands to check user/system info (including one that didn't go as planned) |

| 03 | [Linux File System Hierarchy](./Assignment-03-Linux-File-System-Hierarchy/) | Walking through the root directory and key folders (`/home`, `/etc`, `/bin`, `/tmp`, `/var`) to understand what each one actually does and why it matters for security work |
