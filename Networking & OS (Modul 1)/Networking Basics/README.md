# Topic 1 — Networking Basics

## 📖 Overview

This topic covers the fundamentals of computer networking: how devices are identified and addressed (IP and MAC addresses), how web traffic is exchanged (HTTP vs HTTPS), how domain names resolve to IP addresses (DNS), and hands-on practice with network simulation tools — primarily Cisco Packet Tracer.

## 🛠️ Tools Used

- Cisco Packet Tracer (network design & simulation)
- Web browser DevTools (for HTTPS certificate inspection)
