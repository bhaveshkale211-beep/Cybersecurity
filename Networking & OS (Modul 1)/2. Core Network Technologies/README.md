# Module 01 — Networking and OS Fundamentals

## 📖 Overview

This module builds the foundational knowledge needed before moving into deeper security topics — how networks are designed and addressed, how operating systems and devices communicate, and how core internet protocols (DNS, HTTP/HTTPS) work under the hood. Every topic is treated as a base layer for the offensive and defensive security concepts that come later in this journey.

## 🗂️ Topics in this Module

| Topic | Focus |
|---|---|
| [Topic 1 — Networking Basics](./Topic-1-Networking-Basics/) | IP & MAC addressing, HTTP/HTTPS, DNS, intro to networking and simulation tools (Cisco Packet Tracer) |
| [Topic 2 — Core Network Technologies](./Topic-2-Core-Network-Technologies/) | OSI & TCP/IP models (via live Wireshark packet capture), network topologies, Telnet & SSH remote access |
