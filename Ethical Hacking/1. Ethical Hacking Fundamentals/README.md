# Topic 1: Ethical Hacking Fundamentals

This is where the ethical hacking part of the course starts. Before any tools or attacks, the topic covers how an assessment begins: working out what's public about a target, staying inside an agreed scope, and keeping records clean enough that someone else can check the work.

## Tools I used

- Windows PowerShell (`nslookup`)
- Browser with the Wappalyzer extension
- Google search with advanced operators
- crt.sh (certificate transparency search)
- Public registration and DNS lookups
