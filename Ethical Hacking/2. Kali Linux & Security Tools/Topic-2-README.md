# Topic 2: Kali Linux and Security Tools

Kali Linux is where most of the course's hands-on tools live. This topic goes through the main tools by stage of an assessment, and runs each one against a target I control, so I can see what it does before going further.

## Tools I used

- Kali Linux (VMware)
- Nmap, Nikto, Burp Suite, Wireshark, John the Ripper
- Apache2 (local web server)
