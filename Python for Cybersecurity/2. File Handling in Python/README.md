# Topic 2 — File Handling & Libraries in Python

This is where my Python programs start remembering things and talking to the outside world. Reading and writing files, plus Python's built-in libraries (`os`, `datetime`) and an outside one (`requests`) for fetching data from a web API.

## Tools I used

- Python 3
- VS Code on Windows
- Standard library: `os`, `datetime`, `sys`
- Third-party library: `requests`
