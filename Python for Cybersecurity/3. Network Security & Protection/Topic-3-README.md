# Topic 3 — Network Security & Protection

Python from the network and security side. Starting with sockets, the way two programs actually connect and talk to each other, then using them in small tools that automate everyday security checks.

## Tools I used

- Python 3 (`socket` and `string` modules)
- VS Code and PowerShell on Windows

## Assignments

| # | Assignment | What it covers |
|---|---|---|
| 01 | [Client-Server Chat Application Using Python Sockets](./Assignment-01-Client-Server-Chat/) | A TCP client and server on localhost exchanging three messages, with the socket calls (`bind`, `listen`, `accept`, `connect`, `send`, `recv`) explained step by step |
| 02 | [Cybersecurity Automation Toolkit](./Assignment-02-Cybersecurity-Automation-Toolkit/) | A password strength checker, a log keyword scanner and a basic TCP port scanner, each as a short script |
